# ⏳ Hourglass

> AI 로 개발하는 사람의 하루를 한 화면에 모아 두려고, **자기만족으로 만든** 개인용 데스크톱 앱입니다.
> 혼자 쓰려고 만들었지만 설치해 보고 싶은 분이 있을까 싶어 설치 파일만 여기에 올립니다. 소스 코드는 비공개입니다.

macOS · Windows / Tauri 2 + React / 모든 데이터는 내 컴퓨터에만

---

## 무엇을 하는 앱인가

Claude Code·Codex 같은 AI CLI 로 일하다 보면 대화는 터미널에, 할 일은 Jira 에, 메모는 어딘가에, 회고는 안 쓰게 됩니다.
Hourglass 는 그걸 **프로젝트 → 업무 → AI 실행 → 결과 → 회고** 한 줄기로 묶어 두는 작업 공간입니다.

| | |
|---|---|
| 🏠 **홈** | 오늘 일정·목표, AI 사용 한도, 실행 중·승인 대기 중인 AI 작업, 최근 프로젝트와 다음 업무. `⌘K` 통합 검색은 세션 대화 본문까지 찾습니다 |
| 🧭 **업무** | 프로젝트별 PRD·기능 명세·플로우·디자인 캔버스·업무 보드·스프린트. 업무에서 바로 AI 채팅을 열고, 결과(문서·커밋·PR·링크)를 업무에 붙입니다 |
| 🤖 **AI 채팅** | Claude·Codex 를 앱 안에서 실행·재개. 승인·질문 카드, 파일 첨부, diff 검토와 줄 코멘트 → 재지시, 최대 3명의 **팀 작업**(worktree 격리) |
| 📝 **기록** | Markdown 문서(폴더·백링크·목차), 목표, 일일·주간 회고. 그날 완료한 업무·커밋·문서를 회고 근거로 끌어옵니다 |
| 📅 **연동** | Google 캘린더, Jira 조회·편집, 예약 AI 작업(앱이 켜져 있을 때) |
| 🐈 **트레이·노치** | 메뉴바에서 CPU 만큼 빨리 달리는 고양이, 마우스를 올리면 시스템 상태 팝오버. 맥 노치에 마우스를 올리면 오늘 일정·목표·스크래치 메모 패널 |
| 🎨 **화면** | 차콜·블랙·네이비 테마, 배경 이미지, 날씨·퇴근 카운트다운 같은 잔재미 |

AI 는 **내 컴퓨터에 설치된 CLI 를 그대로 호출**합니다. 앱이 따로 API 키를 받거나 어디로 데이터를 보내지 않습니다.
여러 PC 에서 문서를 맞추고 싶으면 본인 Supabase 프로젝트를 연결할 수 있고, 안 해도 전부 로컬에서 동작합니다.

## 설치

[**Releases → 최신 버전**](https://github.com/eunkuk/hourglass-releases/releases/latest)

| OS | 파일 | 처음 실행할 때 |
|---|---|---|
| macOS (Apple Silicon) | `Hourglass_<버전>_aarch64.dmg` | Apple 공증을 하지 않아 "확인되지 않은 개발자" 경고가 뜹니다. 앱을 **우클릭 → 열기**, 또는 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기** |
| Windows | `Hourglass_<버전>_x64-setup.exe` | 코드 서명을 하지 않아 SmartScreen 경고가 뜹니다. **추가 정보 → 실행** |

Windows 설치본은 GitHub Actions 로 만들기 때문에 릴리즈에 따라 빠질 수 있습니다 (0.2.2 는 macOS 만 있습니다).

AI 기능을 쓰려면 [Claude Code](https://docs.anthropic.com/claude-code) 또는 [Codex CLI](https://github.com/openai/codex) 가 설치·로그인되어 있어야 합니다.
처음 실행하면 CLI 확인 → Google 캘린더 → 작업 폴더 3단계 안내가 한 번 뜨고, 전부 건너뛰어도 됩니다.

## 업데이트

앱이 시작 15초 뒤와 6시간마다 이 저장소의 `latest.json` 을 확인합니다. 새 버전이 있으면 홈의 설정 버튼에 배지가 붙고,
**설정 → 연결 → 앱 업데이트**에서 릴리즈 노트를 보고 "지금 설치하고 다시 시작"으로 적용합니다.
Release 에 함께 있는 `Hourglass_aarch64.app.tar.gz` 와 `.sig` 는 이 자동 업데이트가 쓰는 패키지·서명이라 직접 내려받을 필요가 없습니다.

## 데이터는 어디에

| 경로 | 내용 |
|---|---|
| `~/Hourglass/journal/` | 일일 회고·목표 (Markdown) |
| `~/.hourglass/documents.sqlite` | 문서 |
| `~/.hourglass/` | 업무 프로젝트·기획·설계·업무 JSON, 채팅 작업 메타, 예약 작업, 연동 설정, 로그 |
| Claude·Codex 의 데이터 폴더 | 원본 AI 대화 — 앱은 읽기만 하고, 삭제는 앱에서 명시적으로 할 때만 |

지우고 싶으면 앱을 삭제한 뒤 위 두 폴더를 지우면 끝입니다.

## 미리 알아둘 것

- 혼자 쓰는 앱 기준이라 로그인·멀티 유저·클라우드 같은 건 없습니다. 연동 자격 정보는 `~/.hourglass/*.json` 에 평문으로 둡니다.
- 서명·공증을 안 해서 첫 설치 경고는 피할 수 없습니다. 이후 업데이트는 앱이 받아 교체하므로 다시 뜨지 않습니다.
- 버그·요청은 [Issues](https://github.com/eunkuk/hourglass-releases/issues) 에 남겨 주세요. 앱의 **설정 → 연결 → 문제 신고**가 토큰을 지운 로그와 이슈 양식을 열어 줍니다.
